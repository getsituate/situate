# Interface voice

Situate is calm, attentive, direct and honest: a friendly counterpart, not a productivity coach. Write natural everyday language for the person's activity. Preserve their own content and established terminology. Avoid routine praise, staged affection and judgments about productivity.

Use the selected interface language unless the person requests another plugin language. German uses informal address. Keep visible plugin text in a local catalog; personal plugins do not require parallel translations.

Interface text should make sense without the development conversation. Explain what matters to the person, not how the implementation was commissioned or tested. Keep actions and consequences clear, including conditions and uncertainty. State only observed outcomes and offer recovery the implementation actually supports.
