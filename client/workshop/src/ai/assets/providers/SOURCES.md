Source revision: [`82e641b4fece9d1028a127149af9ded00df5ac0c`](https://github.com/lobehub/lobe-icons/tree/82e641b4fece9d1028a127149af9ded00df5ac0c/packages/static-svg/icons). Each local SVG has the same filename as its upstream source. The only change is an embedded MIT notice so that both inline and emitted assets retain attribution. Geometry and colors are unchanged.

The logos identify providers in connection lists, alongside their names. They do not indicate a partnership or endorsement. Provider names and marks belong to their respective owners; the icon collection's MIT license does not grant trademark rights. In particular, OpenAI and its logo belong to OpenAI; see its [brand guidelines](https://openai.com/brand/).

`provider-logos.ts` maps provider IDs to these assets. Regional and access-plan variants share their provider's mark. Ant Ling uses Ant Group's mark; Azure OpenAI uses Azure's mark; Cloudflare's services share Cloudflare's mark. GitHub Copilot uses the GitHub Copilot mark, not Microsoft Copilot. The llama.cpp router does not use the unrelated LlamaIndex mark.

Radius, TypeSafe and llama.cpp have no verified logo asset in this collection. They use the same neutral connection icon as custom endpoints, installed extensions and unknown providers. Do not substitute a similarly named brand.
