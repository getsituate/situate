## Description

The proposed design used Situate-owned hierarchical tags to organize and filter documents across connected sources, with manual assignments and automatic categorization.

## Rationale

There is not enough user evidence that maintaining a separate classification in Situate solves a recurring document-finding problem. Any future proposal should start from observed user workflows rather than carry this design forward.
