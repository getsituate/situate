# Visual direction

Read the chosen interaction concept, intended device context and any existing brand or component guidance. Do not assume a settled brand or import another project's identity.

Choose typography, density, spacing, color roles and component treatment to support reading, navigation and action recognition. Reuse existing tokens where present. Explain consequential choices through the task and audience rather than trend labels.

Compare a few visual treatments only if a visual decision remains open. Use the same content and interaction structure for fair comparison. Avoid decorative elements that compete with the user's content or imply unsupported functionality.

Check long titles, dense content, small containers, text enlargement, contrast and reduced motion. Use licensed assets only; do not fetch fonts or imagery without checking usage and redistribution terms.

Deliver the smallest useful visual sample and a short account of its reusable choices. Do not create a full brand guide or design system unless requested. Mark proposed tokens as provisional until selected.
