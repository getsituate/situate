# Generate variations

Identify one decision and shared scenario. Keep constraints and sample content consistent so differences are interpretable.

Choose a small useful set, normally two or three approaches. State each approach's defining difference before drawing it: navigation, grouping, interaction sequence, information density or degree of direct manipulation. Different colors alone do not constitute different interaction concepts.

Use familiar patterns when they fit. Include a less familiar approach only when it offers a plausible task benefit, not to satisfy a novelty quota. Exclude options that contradict approved constraints unless the user explicitly asks to reconsider those constraints.

Present options in a common comparison view when practical. For each, show the task path, benefit, cost, highest-risk assumption and evidence needed. Keep fidelity comparable and do not make a preferred option look more finished.

Recommend an approach with reasons tied to user outcomes and known evidence. Distinguish usability claims from taste. If options remain indistinguishable, propose the smallest test that could separate them rather than asserting a winner.
